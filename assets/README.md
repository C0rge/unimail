# UniMail 应用图标设计说明

本文件是 `assets/icon.svg`（深色）与 `assets/icon_light.svg`（浅色）的设计依据。
图标源文件本身**刻意保持纯净**（只有图形元素、无注释）：Qt 的 `QSvgRenderer`
对 SVG 内部的 XML 注释支持不完整，带注释的源文件会静默解析失败，而报错只
是一句「SVG 无法解析」。设计说明因此放在这里，不放进 SVG。

## 造型：层叠信封（stacked envelope）

三层错位叠放的圆角矩形，顶层填充、下两层描边，顶部三个圆点。

**为什么是抽象几何而不是具象信封：**

1. **具象信封在小尺寸下不可读。** 16×16 的任务栏图标是 Windows 上最重要的
   使用场景，信封翻盖的 V 形在这个尺寸下会并成一个实心块，轮廓糊掉。
2. **三层叠卡直接表达「多账号聚合」。** 本项目区别于单账号客户端的核心正是
   统一收件箱（QQ / 163 / Gmail / Outlook / 自定义 IMAP 聚在一处），
   层叠的卡片是这件事的图形同构。
3. **纯圆角矩形 + 圆点，没有尖角、没有细线。** 与界面里所有控件的圆角语言
   （`RADIUS` 令牌）一致，缩放时不会出现某个尺寸下尖角发虚的问题。

**三个圆点**同时承担两个语义：既像邮件列表里的「未读」标记，也让顶层卡片
不至于是一块死板的纯色面。

## 设计语言：延续 `unimail/ui/icons.py`

| 约束 | 本项目图标集 | 应用图标 |
|---|---|---|
| 视窗比例 | 24×24 网格 | 同一套比例放大到 512×512 |
| 描边宽度 | 1.8px（在 24 视窗下） | 30px（在 512 视窗下，等比） |
| 端角 | 圆头圆角 | `rx=40` 大圆角 |
| 取色 | 只从主题调色板取 | 深色 `accent=#4c8dff`，浅色用更深的 `#2d5aa8` |

用 512 画布而不是 24，是为了 16px 输出时仍有足够的采样精度；比例关系与
24 视窗保持一致，所以视觉重量与界面内图标是协调的。

## 深浅两版

Windows 会在不同位置以不同背景呈现图标：任务栏（跟随系统深浅）、
Alt+Tab 列表、窗口标题栏、资源管理器。因此提供两版而非一版：

| 文件 | 场景 | 取色 |
|---|---|---|
| `icon.svg` | 深色背景（默认，Windows 任务栏常态） | 顶层 `#4c8dff`，描边层同色不同透明度 |
| `icon_light.svg` | 浅色背景（浅色任务栏 / 浅色标题栏） | 顶层 `#2d5aa8` 加深，避免浅蓝在浅底上发虚 |

两版**同形异构**：几何完全一致，只改色值。这样同一枚图标在深浅两套系统
主题下都不需要额外处理，也不会出现「换了主题图标变了」的割裂感。

## 构建产物

`assets/*.svg` 是源文件（进版本库），以下都是**构建产物**（不进版本库）：

| 产物 | 生成方式 | 用途 |
|---|---|---|
| `dist/icon.ico` | `python tools/make_icon.py` | PyInstaller `--icon`、exe 资源 |
| `assets/icon_dark_{32,64,256}.png` | 同上 | Qt 侧兜底、文档插图 |
| `assets/icon_light_{32,64,256}.png` | 同上 | 浅色主题文档插图 |

**修改图标请改 SVG 源文件后重跑 `tools/make_icon.py`**，不要直接编辑 `.ico`——
后者是二进制，改完就说不清对应哪一版设计了。
